# 『ねえ、起きてる？』引き継ぎ資料（Claude Code 向け）

最終更新: 2026-11-25 / 制作: レッド（RED FREE GAMES）／ Muse が構築・検証

## 1. ゲーム概要

深夜1時、メンヘラ彼女ミサキからの「尋問電話」を耐えきるブラウザゲーム。
眠気（時間で上昇、100で寝落ちバレ）と不信感（悪い返答で上昇、100で別れる）の2ゲージの板挟みで、全問答えきればクリア。眠気が限界に近づくと「本音」ボタンが出現し、押すとその質問専用の一言で即ゲームオーバー（それがシェア素材になる）。

- 一言コンセプト: 「眠いのに終わらない、彼女からの尋問電話」
- 想定プレイ時間: 2〜4分／ステージ
- 公開状態: **未公開**（公開は本人の GitHub Pages `red-freegames.github.io` で本人が行う）

## 3. ゲーム仕様（確定数値）

### 質問データ
- 通常質問プール **25問**（QUESTIONS）。各問：質問文 `q`、本音 `honne`、選択肢3つ `opts`（`t`=返答、`d`=不信感増減、`s`=眠気増減、`r`=彼女の反応）
- 選択肢の素点は原則：良い −6／眠気+2、無難 +4／0、悪い +14／眠気−4（「良い返事は安心して眠くなる、悪い返事は怒られて目が覚める」というトレードオフが設計の核。崩さないこと）
- **地雷質問 3問**（TRAPS、`trap:true`）：全選択肢 `d>0`。最終ステージのプールにのみ混ざる
- 毎回ステージの必要数だけランダム抽選し、出題順もランダム。**選択肢の表示順も毎問シャッフル**（かつて先頭が常に正解だった問題への対策。戻さないこと）
- 相づちモノローグ 6本（AIZUCHI、`zone` は成功ゾーン位置）

### ステージ（STAGES 配列が唯一の定義源）
| | ステージ1「まだ起きてる？」 | ステージ2「ねえ、起きてる？」 | 最終「もう疲れた」 |
|---|---|---|---|
| 質問数 totalQ | 10 | 15 | 18 |
| 眠気 tick（/秒） | 0.32 | 0.45 | 0.56 |
| 遅答 slowSec / 罰 | 12秒 / +4 | 9秒 / +6 | 6秒 / +8 |
| 不信感 suspStart | 0 | 0 | **30** |
| イライラ creep（/秒） | 0 | 0 | 0.22 |
| ほっぺた slapMax | 4 | 3 | 2 |
| 本音出現 honneAt | 70 | 65 | 55 |
| 相づち azBase / azWidthMul | 2.1 / 1.3 | 1.7 / 1.0 | 1.25 / 0.7 |
| 相づち発生 aizuchiAfter | 2,5,8 問後 | 2,5,8,11,14 問後 | 2,5,8,11,14,17 問後 |
| 加速 accelDiv / rampDiv | 14 / 360 | 10 / 240 | 7 / 200 |
| 波 start/cycle/dur/倍率 | 55 / 70 / 7秒 / ×1.5 | 45 / 55 / 8秒 / ×1.8 | 38 / 45 / 7秒 / ×2.0 |
| rage | − | − | ✓ |

- デフォルト選択はステージ2。ステージクリアは `nk_clears_v1` に記録され、選択カードに 🏅 が付く（ロック式ではない。全ステージ最初から遊べる）

### 眠気の加速（sleepRate / advanceTime、ctx = {phase, qElapsed, callElapsed, wave}）
```
倍率 = (1 + 通話経過秒 / rampDiv)
     × (質問フェイズ中のみ 1 + その質問の経過秒 / accelDiv)
     × (波の間だけ waveMul)
上限 ×6 ／ 実速度 = tick × 倍率
```
- 眠気の波（isWave）: `t >= waveStart` かつ `(t - waveStart) % waveCycle < waveDur`。**乱数ではなく固定スケジュール**（運ゲー化を嫌う本人の方針）。開始時に sys バブルで予告、ゲージ横 `#rateMul` に倍率表示
- 反応フェイズ（phase='reaction'）では時間は進むが終了判定をしない（回答直後の理不尽な終了を防ぐ既存仕様）

### 機嫌システム（moodOf）
- 不信感 **30以上 = doubt（疑ってる）**：`d>0` の回答に **+2**
- 不信感 **60以上 = bad（不機嫌）**：`d<0` の回復が **半減**（ceil）、`d>0` に **+3**
- 通話ヘッダー `#callStat` に状態と色を表示
- 最終ステージの rage は `d<0` 半減を常時適用（bad と重なっても半減は1回だけ）。さらに良い回答への反応文が RAGE_GOOD_REACTS（5種、質問番号で循環）に差し替わる

### その他ルール
- 遅答：`elapsed > slowSec` で不信感 +slowPenalty
- 相づち：成功 −4／失敗 +7。ゾーン幅 = 元幅 × azWidthMul × (1 − 眠気/300)、上限 0.34。持続時間 = max(0.85, azBase − 眠気×0.005)
- ほっぺた：眠気 −12／不信感 +5、ステージ毎の回数上限
- 本音ボタン：眠気 ≥ honneAt で出現。その質問の `honne` を言って即「本音漏れ」エンド
- エンディング4種：clear（おやすみ）/ sleep（寝落ちバレ）/ breakup（別れる）/ honne（本音漏れ）。図鑑は `nk_endings_v1`（※2026-11-27に7種へ拡張。§10参照）
- シェア：結果画像キャンバス 1200×630（ステージ名入り）、X シェア文に `#ねえ起きてる`

### バランス実測（検証ハーネスのシミュレーション、2026-11-25 時点）
- ステージ2・上手いプレイ（4秒回答＋相づち成功＋ほっぺた1回）：クリア、最終眠気 **82**（加速導入前は52）
- ステージ2・1問10秒悩むプレイ：**8問目で寝落ち**（加速が効いている証拠）
- ステージ2・全問ワースト：7〜8問目で破局／全問無難：不信感46で生存
- ステージ3・熟練プレイ（2秒回答＋ほっぺた活用）：クリア、最終眠気 **76**
- ステージ1・無難な回答のみ：クリア（入門として意図通り）

## 4. UI の確定仕様（本人の指摘で決まった事項。戻さないこと）

- 画面は固定高（100dvh／PC は 96dvh）。**スクロールするのは会話ログ `#log` だけ**（ページ全体が伸びる作りは本人が却下）

## 5. 技術上の注意（過去の事故を含む）

- **localStorage は必ず try/catch で囲む**（storeGet/storeSet 経由）。Muse アプリ内ブラウザのサンドボックスでは無防備な `localStorage.getItem` が例外を投げ、スクリプト全体が死んで真っ白になる事故が別ゲーム（ワンクリック・ハッカー）で発生した
- 外部リソース・ライブラリ不使用。単一 HTML で完結させる（本人の公開形態が GitHub Pages のため）
- テスト作業ファイルは `tests/` 配下に置くこと。`/tmp` はセッション間で消えることがある

## 9. ボット検証と修正（2026-11-25 追記）

`node tests/bot.js [試行数]` で、本物の index.html（ロジック＋UI）を仮想時計の上で動かし、11種類のプレイヤーモデル × 3ステージを大量プレイさせて結末分布と異常（ゲージ範囲外・本音ボタンの誤表示・到達数の食い違い・限界超えのままクリア・進行停止）を集計する。

このボットで見つかり、修正した不具合：
- 結果画面の「到達：N問目」と Xシェア文の問題番号が最大1ずれていた → 最後に出題された問題番号（`S.qNo`）に統一
- 最終問の反応中に眠気／不信感が100に達しても「クリア」になっていた → `afterReaction` で清算してから判定
- 開始・結果画面の中身が画面より高いと、上端（タイトル・遊び方）が見切れてスクロールでも戻れなかった
- iPhone SE 相当の画面で、眠気が高いと会話ログが約16pxに潰れ、ほっぺたボタンが画面外にはみ出していた → 縦700px以下で操作エリアを詰める
- 相づちマーカーが100ms刻みで描画されていて、最終ステージのゾーン（約0.1秒）を飛び越えて見えていた → requestAnimationFrame で描画
- ティックが「1回=0.1秒」固定だった → 実経過時間（上限0.25秒）で進める。画面を離れている間（ロック・タブ切替）は通話を一時停止
- 「もう一度電話に出る」（reload）で選択ステージがステージ2に戻っていた → `nk_stage_v1` に記憶

## 10. 追加機能（2026-11-27）

本人と合意して実装したもの。数値はボット（`node tests/bot.js`）で調整済み。

- **悩み猶予**：質問中の眠気加速は、出題から `accelGrace` 秒（s1/s2=3〜4秒、s3=2秒）を過ぎてから効く
- **甘えモード**：良い答え（d<0）が2連続以上で、追加の眠気 `comboSleep×(連続数−1)`（上限 `comboMax`）。無難・悪い答えで途切れる。通話ヘッダーに「甘えモード💗」。最終ステージは不機嫌なので発生しない（comboSleep=0）
- **追及**：mem 付きの「調子のいい約束」（8種）を選ぶと、3問以上あとの出題が FOLLOWUPS の追及質問に差し替わる。ステージごとの上限は `fuMax`（1/2/3）。地雷質問は差し替えない
- **エンディング7種**：clear / herSleep（甘えモード5連続以上を経験＋不信感5以下でクリア）/ brink（眠気90以上でクリア）/ sleep / breakup / slapped（ほっぺたの音で破局）/ honne。判定は `finalEnding()`
- **称号**：`titleOf()` がプレイ内容から1つ選ぶ。結果画面・結果画像・Xシェア文に出る
- **本音図鑑**：本音エンドで言った一言を `nk_honne_v1` に記録。全36問（通常25・地雷3・追及8）。未解放の追及は質問文も伏せる

### ステージ2の数値変更
tick 0.45→0.32、rampDiv 240→300、accelGrace 4、comboSleep 2、comboMax 5.5。甘えモードで増える眠気を、基本の眠気速度を下げて相殺した。

|---|---|---|---|

## 11. ステージ別の質問プール（2026-11-27）

本人の指示で、質問をステージごとに完全に分けた（重複なし）。`POOLS = [Q_S1, Q_S2, Q_S3]` が出題元で、`QUESTIONS` は3つを連結したもの（図鑑・テスト用）。

| | 雰囲気 | プール | 出題 | 追及の種 |
|---|---|---|---|---|
| ステージ1 | 軽いメンヘラ（かわいいヤキモチ） | 18問 | 10問 | plan / surprise / savedPhoto |
| ステージ2 | 重度のメンヘラ（位置情報・連絡先削除・元カノのインスタ等） | 22問 | 15問 | photo / only / history / pass / exDeleted |
| 最終 | 疲れ切って怒っている（責める・試す・突き放す） | 20問＋地雷3問 | 18問 | fix / yawn / never |

- 元の25問は雰囲気でステージ1に5問、ステージ2に12問、最終に8問を振り分け、残りを新規に書いた
- 追及は11種（最終ステージ用に fix / yawn / never を追加）。本音図鑑は全74問で、ステージ別に分けて表示
- 各ステージの第一声は `STAGES[].hello`
- 選択肢の点数（良−6/+2、無難+4/0、悪+14/−4）は全問で据え置き。ボットでのクリア率は §10 とほぼ同じ
