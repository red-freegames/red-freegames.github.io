## 1. ゲーム概要

- **タイトル**: 『ダンシングマニア』（仮タイトル・未確定）
- **一言で**: 変な踊りが人から人へ感染していく3Dブラウザゲーム。プレイヤーは「患者ゼロ」（最初に踊り出す1人）となり、制限時間内に広場の全員を踊らせる。警備員がプレイヤーを捕まえに来て、踊る人を説教で正気に戻す。
- **モチーフ**: 1518年にストラスブールで実在した「ダンシングマニア」（1人の女性から始まり1ヶ月で400人が踊り続けた集団ヒステリー事件）。
- **状態**: 試作完成・検証済み。**未公開**。作者（レッド / RED FREE GAMES）の試遊フィードバック待ちの段階。
- **プラットフォーム想定**: スマホ+PCブラウザ。単一HTMLファイルで GitHub Pages に置く想定（作者の他作品と同じ形式）。

## 3. アーキテクチャ

- core は `globalThis.__DM__ = { STAGES, CFG, ARENA, createGame, rankFor, mulberry32 }` を公開。
- `createGame(seed)` がゲーム状態オブジェクト G を返す。乱数は mulberry32（シード固定で決定的）。
- ループ: UI が毎フレーム `G.update(dt, input)` を呼び、発生したイベントを `G.drainEvents()` で回収して演出に使う。
  イベント種別: `stage / infect / cure / catch / fever / clear / goal / over`。
- UI は `globalThis.__DM_UI__ = { get G(), setupStage }` を公開（スモークテスト用）。
- 座標系: 地面は XZ 平面、移動可能範囲は ±27 の正方形（`ARENA=27`）。角度は `atan2(x, z)` 形式（+Z向きが0）。

## 4. ゲーム仕様（数値は dance-core.js の CFG / STAGES が正）

### ルール
- プレイヤーは常時踊っている。踊っている人（プレイヤー or 感染者）の半径 **4.3** 以内に約 **0.7秒** 居た通行人が感染して踊り出す（「頑固な人」は **1.8秒**、黒っぽい服が目印）。
- 感染者はゆっくり移動しながら周囲を感染させる。最後の感染から **2.5秒** 以内の連続感染は「連鎖」としてカウント（HUDに残り時間ゲージ表示）。
- **フィーバー**: 連鎖が **12** に到達すると **5秒間**、感染範囲×1.5・感染速度×1.6。警備員も踊り出して無力化（追跡・説教なし）。
- **人だかり**: 各ステージに屋台が3〜5箇所あり、周囲に通行人の約45%が固まって立っている（頑固な人は入らない）。感染の着火点。
- **警備員**: プレイヤーが半径14以内に入ると追跡（速度7.5、プレイヤーは9.4）。接触でハート−1（全3個、捕獲後は2.5秒無敵＋警備員は持ち場へ帰還）。プレイヤーが遠い時は最寄りの感染者に近づき、2.2以内で2秒説教すると正気に戻す（戻った人は5秒間再感染免疫）。
- **勝敗**: 全員を同時に踊らせたらステージクリア（即時）。ハート0か時間切れでゲームオーバー。全3ステージ制覇で全クリア。
- **スコア**: 感染1人 = 100 + (連鎖数−1)×30。クリアボーナス = 残り時間×10 + ハート×200。

### ステージ

|---|---|---|---|---|---|---|
| 1 | 駅前広場 | 26 | 4 | 1 | 60秒 | 3 |
| 2 | 結婚式の披露宴 | 38 | 7 | 2 | 70秒 | 4 |

### 称号（rankFor）
75000〜「ダンシングマニア」/ 50000〜「踊りの感染源」/ 28000〜「広場のスター」/ 10000〜「かけだしダンサー」/ それ未満「ただの通行人」。

### 踊り（dance-ui.js の dancePose が正）
- 全ダンサーが**グローバル位相 `p = t × 9.0` を完全共有**し、寸分違わずシンクロするのが本作のキモ。個別位相に変えないこと。
- 8拍サイクル内の仕掛け: 1拍目=両手上げの決めポーズ / 5〜6拍目=左腕の風車回転+右腕の羽ばたき / 8拍目=変なポーズで全員フリーズ。
- 16拍に1回、全員同時にその場で1回転（`danceSpinOffset`）。
- 関節は数式駆動のプロシージャルアニメーション。モデルデータ・外部アセットは一切なし。

### 描画まわりの決まり事（作者の指摘で確定した事項。戻さないこと）
- **感染範囲の円と影は「地面専用グループ groundG」の子**。キャラ本体（root）に入れると踊りの傾き・跳ねで円が歪んで見えるため分離した。本体は root、地面物は groundG、両方を syncPersons で位置同期する。
- 円の見た目: 主人公＝太い輪（幅0.38）+不透明度0.6+明滅 / 他キャラ＝細い輪（幅0.18）+不透明度0.18+内側の塗り0.03。人数が多いと重なって見づらいため他キャラ側は意図的に薄い。
- 警備員は**蛍光イエロー（0xffd400）の服+白い反射帯+同色キャップ**。一般客のパレットに無い色で即判別させる確定仕様。
- プレイヤーは赤シャツ+金ズボン+頭上に▼マーカー。
- 結果画像は WebGL キャンバスのスナップショットを使うため `preserveDrawingBuffer: true` が必須（外すと結果画像が真っ黒になる）。

### 操作
- ドラッグ = 仮想スティック（指を置いた所が中心。半径46pxを超えると中心が指に追従、デッドゾーン12px、方向のみで常に全速）/ WASD・矢印キー。2本目の指は無視。pointercancel・blur・visibilitychange で入力を解除（動きっぱなし防止）。
- 音は iOS 対策で、ボタン押下・画面タッチの中で AudioContext を生成/resume（unlockAudio）。捕獲・フィーバーで振動（対応端末のみ）。
- 音は WebAudio の簡易シンセ。ON/OFF は localStorage `dm_sound`。

## 6. 開発履歴（作者のフィードバックと対応）

1. 初版: 3D試作（22/32/44人、90/105/120秒）。「インベーダーみたい」とは別ゲーム（5秒ストップ）への感想。
2. 踊りを強化（非対称・風車・羽ばたき・回転・フリーズ追加）。
3. 警備員を蛍光イエロー化。
4. 円の視認性: 太く・濃く・内側の塗り追加 → その後「円が踊りで歪む」指摘で groundG 分離。
5. 連鎖強化一式: 連鎖タイマー可視化、人だかり、フィーバー、人数増（26/38/52）、制限時間を 60/70/90秒 に再調整、称号ライン引き上げ。
6. 他キャラの円だけ薄く・細く（人数増で見づらくなったため）。
7. スマホ最適化: 縦持ちで画角を広げカメラを引く（fitCamera: 縦横比1:2でfov 50→64・距離×1.28、横長は従来どおり）、仮想スティック表示、iOS音声アンロック、セーフエリア（ノッチ）対応、小画面/横持ちのパネル・HUD縮小、ピンチ/ダブルタップ拡大の抑止、重い端末で解像度を自動で下げる（adaptQuality）。ゲームロジック（dance-core.js）は無変更。
